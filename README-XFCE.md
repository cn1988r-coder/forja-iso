# BuildMaker XFCE Dark

## Painel inferior

Um painel XFCE de 46 px, largura total, alinhado à parte inferior:

1. Whisker Menu com ícone V azul do BuildMaker.
2. Docklike Taskbar imediatamente ao lado do menu, agrupando janelas do mesmo aplicativo.
3. Separador expansível para manter os indicadores à direita.
4. Bandeja, volume, energia, monitor CPU/RAM, relógio e mostrar área de trabalho.

## Aparência

- Orchis-Dark com variante azul/preta e cantos arredondados.
- Papirus-Dark e Bibata-Modern-Ice tamanho 24.
- Noto Sans 10.
- Fundo grafite, detalhes azul elétrico e texto claro.
- Compositor desligado, sem blur, transparência ou animações chamativas.

## Personalização

O painel continua sendo o painel normal do XFCE: botão direito para adicionar/remover itens e abrir as preferências. Não é uma barra bloqueada por um aplicativo externo.

## Limite do perfil atual

Este repositório contém a configuração e o instalador do desktop XFCE. Isso não equivale a uma ISO inicializável: para isso ainda é necessário integrar um perfil Archiso completo, configurar o Calamares e validar a instalação em máquina virtual.
