# BuildMaker XFCE Dark

O BuildMaker usa XFCE, não LXQt, KDE, MATE ou SDDM.

## Barra inferior
Painel único com 46 px, largura 100%, alinhado à parte inferior:
1. Whisker Menu.
2. Lançadores rápidos.
3. Lista de janelas com agrupamento por aplicativo, para que várias janelas do Firefox apareçam em um único botão.
4. Monitor do sistema e área de notificação.
5. Volume, rede, Bluetooth, energia, relógio e botão de mostrar área de trabalho.

## Personalizar com o mouse
Clique com o botão direito na barra e abra **Painel > Adicionar novos itens** para incluir componentes. Em **Painel > Preferências do painel**, desbloqueie a barra para mover e reorganizar itens. O menu de contexto de cada item permite removê-lo ou abrir suas propriedades.

## Aparência
Grafite/preto com azul elétrico, Materia-dark, Papirus-Dark e Bibata-Modern-Ice tamanho 24. Efeitos visuais e compositor desativados para manter a interface estável e leve.

## Login e aplicativos
LightDM GTK Greeter. Pamac, Firefox e Calamares fazem parte da seleção de pacotes. A presença do pacote Calamares não substitui uma configuração funcional do instalador.
