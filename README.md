# VENOM OS MATE: branch histórica arquivada

Esta branch preserva o histórico da antiga experiência MATE/Community. Ela **não é uma edição ativa** e não deve ser usada para gerar ISO.

A edição oficial VENOM MATE está sendo mantida na branch `optimize/venom-iso-size`, baseada diretamente no Arch Linux oficial, com Archiso e Calamares 3.3.14 para instalação online.

As únicas edições planejadas são VENOM MATE, VENOM XFCE e VENOM Window Maker. Esta branch não representa uma quarta edição nem uma base operacional Manjaro.

- Nenhum workflow de Manjaro pode ser executado.
- Não usar `buildiso`, `manjaro-tools` ou repositórios Manjaro.
- Não iniciar build ou publicar ISO nesta branch.
- Pacman administra atualizações normais; VENON permanece independente e manual.
- Consultar `optimize/venom-iso-size` para o estado técnico ativo da edição MATE.
