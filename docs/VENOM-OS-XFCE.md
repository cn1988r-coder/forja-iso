# VENOM OS XFCE

## Scope

This edition retains XFCE and its session configuration packages, including `comm-xfce-config` and `comm-xfce-datetime`, because they form part of the desktop structure the user asked to preserve.

Retained applications: Firefox and Pamac GTK. IPTVnator is installed on first login from the AUR as `iptvnator-bin`.

Unselected bundled applications, vendor logos, wallpapers, welcome tools, and vendor branding are excluded. The dark GTK theme remains enabled. The operating-system identity, validation job, compilation job, and published artifact use only the name VENOM OS.

The current signed XFCE support repository is used only for the XFCE session configuration and its required trust packages. The obsolete `repo.biglinux.com.br` URL is not used.

## Installer

This test image does not include Calamares. The final VENOM OS installer is a separate component and must not be replaced with a third-party installer.

## Test status

A successful static validation is not proof that the ISO compiles or boots. The workflow must complete before an ISO artifact can be reported.
