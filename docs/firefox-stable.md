## Integração no perfil XFCE

O perfil EndeavourOS/Arch da Forja OS instala o pacote `firefox` pelos repositórios configurados. A lista de pacotes não fixa manualmente a versão do navegador: a versão efetivamente instalada durante cada compilação é a versão disponibilizada pelo repositório no momento da compilação.

Portanto, **160.0 é o registro da versão estável upstream verificada nesta data**, não uma fixação de pacote nem garantia de que uma ISO futura instalará exatamente essa versão.

## Acompanhamento

Ao atualizar este registro, consultar primeiro as notas oficiais do canal Release da Mozilla e registrar a versão e a data de lançamento. Não confundir Stable com Beta, Developer Edition, Nightly ou ESR.
